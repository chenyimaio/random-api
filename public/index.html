随机图片

随机数

—

随机字符串 / 口令

—

值必须在 1 和 256 之间。建议 14 位以上。

占位

接口

GET /api/number随机数：?min=&max=&n=&unique=&decimals=
GET /api/string随机字符串/口令：?length=&chars=&lower=&upper=&digits=&symbols=&underscore=（length 可给列表）
GET /api/daily每日一句：同一天所有人拿到同一句，带一天缓存
GET /api/hitokoto一言，字段兼容 hitokoto（现成组件直接可用）。支持 ?type=d
GET /api/quote一言简版：{ quote, from, fromWho, type }
GET /api/quotes?n=5批量随机，不重复
GET /pc/dm 等四类路径/pc/dm 电脑二次元 · /mobile/dm 手机二次元 · /pc/fjbz 电脑风景 · /mobile/fjbz 手机风景。直接返回图片字节，地址不变，每次刷新都是新图
GET /api/image图片信息：{ url, class, device, genre, width, height, format, formats }。支持 ?class=、?device=、?genre=、?format=
GET /api/random直接返回图片字节（不再 302），可写进 <img src>。按 UA 自动横竖，支持 ?genre=、?device=、?class=、?format=
GET /api/all一言 + 图片一起返回

全部允许跨域，随机接口不缓存。
